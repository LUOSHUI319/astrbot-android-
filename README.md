# AstrBot 安卓端 · 洛水内置版

把 AstrBot 的安卓端做了一次工具整合打包，做成可以直接离线安装的成品包。

## 为什么做这个

新手第一次跑 AstrBot 的时候，通常要联网去拉一堆依赖，源和 GitHub 都不太稳，
网络一波动，安装和配置的时间就被无限拉长，有时候直接失败重来。

这个包把常用的依赖预先打包进去了，装上就能用，省掉第一次的网络折腾。

## 下载

因为 GitHub 仓库单个文件限制 100MB，apk 不放在仓库里，请到 Releases 页面下载：

## 安装

1. 到 Releases 下载 apk
2. 手机上允许「未知来源应用」安装
3. 安装完成后按应用内提示配置

- 包体接近 700MB，建议在 WiFi 环境下载
